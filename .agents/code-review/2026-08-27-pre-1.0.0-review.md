# Pre-1.0.0 final review — 2026-08-27

Adversarial pass before tagging v1.0.0, weighted toward code changed since the
2026-08-27 remediation (port-sharing, proxy hardening, terminal bridge,
frontend cosmetics). Two independent reviewer agents + a direct pass. Several
findings were verified live or against React/tmux source.

**Verdict: REQUEST CHANGES — do not tag 1.0.0 yet.** 4 blocking, 8 important,
~15 nits. Two items need an operator decision (marked ⚑).

## Blocking

| ID | File | Finding |
|----|------|---------|
| B1 | `web/src/lib/clips.ts:71` + `SidePanel.tsx:398` | **Clips tab infinite render loop.** `getClips()` runs `fresh()` = `.filter().slice()` → a new array ref every call. `useSyncExternalStore` (N8) compares snapshots by identity, so the snapshot never stabilizes → infinite re-render the instant the Clips tab opens. Verified against React source. e2e never opens that tab. Fix: `getClips` returns a stable ref (only reassign in add/clear/lazy-load); prune TTL on write, not read. |
| B2 | `internal/httpapi/shares.go:51` + `auth.go:59` | **Preview ACL satisfied by username-slug collision.** `allowed = user == u.Username \|\| emailIn(...)`; for a guest `u.Username = DeriveUsername(email)`, which drops the domain (`alice@x.com` and `alice@gmail.com` both → `alice`). A hostile Google account whose local-part slugifies to a styrman user's slug gets **owner-level** access to *all* that user's project previews, unshared. Fix: gate the owner-branch on `s.users.IsAuthorized(u.Email)` and never set `Username` for preview-only identities. |
| B3 | `internal/terminal/bridge.go:357` + `conversation.go:138` | **tmux `has-session -t conv-1` prefix-matches `conv-10`.** Terminal IDs are sequential ints, so with ≥10 terminals, a real exit of terminal 1 sees `conv-10` alive → false "session alive" → wrong close code (N16 regresses). Same defect makes `kill-session` able to kill the wrong session. Fix: exact-match target `"=" + name` in both. |
| B4 ⚑ | `deploy/docker-compose.yml:78` + `userstore.go` | **Sharing has no safe production config.** `caddy_admins: ${STYRMAN_ALLOWED_EMAILS}` → ingress is role-gated: a guest not in that list is 403'd at the ingress and never reaches `authGuard` (feature silently dead). Adding them to `STYRMAN_ALLOWED_EMAILS` makes them `IsAdmin` → full dashboard/terminals/files/user-mgmt. The live test earlier passed only because it hit the server directly, bypassing the ingress. Needs an ingress-mode decision (below). |

## Important

| ID | File | Finding |
|----|------|---------|
| I1 | `shares.go:72` + `server.go:255` | Preview-shaped paths that don't route to `proxyPort` (`/proxy/foo`, `/p/x/port/y`) fall through to the SPA catch-all → **200 + static shell to an unauthorized guest**. No data leak (assets 403), but the authz heuristic is decoupled from the route table. Fix: catch-all rejects `isPreviewPath` guests, or scope the check to the proxy routes. Verified live. |
| I2 | `bridge.go:355` | `sessionAlive` drops `orch.Exec`'s error and maps every failure (dockerd hiccup, 3 s timeout) to "gone" → false "Paused" on a live session; violates the no-silent-drop Go standard. Also adds up to 3 s latency to every close. Fix: log the error; treat error as "reconnect", clean non-zero as "gone". |
| I3 | `bridge.go:336` | The probe runs on **every** browser disconnect (tab close/nav), not just `tmux detach` — an extra exec round-trip per close, ×10 VMs. Fix: skip the probe when the WebSocket is already dead (close code is discarded then anyway). |
| I4 ⚑ | `proxy.go:132` | `CSP: sandbox` (opaque origin) is likely to break the *primary* preview case — a dev SPA calling its own same-origin backend with cookies. Trade-off vs. blocking a malicious (agent-generated) preview from scripting the owner's styrman session. Needs a decision (below). |
| I5 | `deploy/caddy/ingress/generator.go:273` | `X-Caddy-Email` is derived from `{http.request.header.X-Token-User-Email}`; the incoming `X-Token-User-Email` is stripped *after*, not before. If caddy-security uses `Header.Add` (unverified) a client value could win → identity spoof. Cheap defensive fix: strip the four upstream headers *before* `authorize`. |
| I6 | `SidePanel.tsx:141` | A failed/not-yet-loaded `getShares` renders as "shared with nobody"; the next add PUTs `[newEmail]` and **wipes the real list**. Also a 30 s stale-read lost-update window. Fix: disable input until `data` loaded; use the PUT response as state, not a re-poll. |
| I7 | `proxy.go:57` | `EnsureSelfAttached` = one Docker `NetworkConnect` per proxied request, now guest-reachable at ~100 rps/IP → shared-`docker.sock` pressure + attacker-paced log growth. Fix: cache the attach per project. |
| I8 | `proxy.go:41` | `previewAccess` runs the full cross-owner scan (`os.ReadDir` + `space()` under the global `spacesMu`, which does FS work) *before* port validation, on arbitrary guest input. Fix: validate port first; index `projectID→owner`; don't hold `spacesMu` across FS. |

## Nits (representative — full list in the two agent reports)

- Version reports `0.0.0`: `STYRMAN_VERSION` build-arg never passed by compose.
- Share list: no size/length cap; no audit log on grant/revoke.
- No tests for `internal/terminal/` (sessionAlive) or `previewAccess` authorization.
- Credential strip is a denylist; prefer an `X-Caddy-*` prefix sweep + `Proxy-Authorization`.
- `proxy.go` path-traversal payloads (`..%2f`) forwarded un-normalized to the guest app.
- `u.Username = owner` mutates the identity struct (footgun); use a separate var.
- Share is project-wide, not port-wide — a guest can reach ANY port ≥1024 in the VM (port-scan). UI copy "only the port links you send them" overstates it.
- `/api/health` is exempt *before* the ingress-token check and calls `orch.Adopt` (Docker list) — unauthenticated from a shared bridge.
- Remove-button uses `visibility:hidden` → keyboard-unfocusable; use `opacity`.
- `setEmail("")` before the PUT resolves loses the typed address on failure.
- Enter handler fires during IME composition.
- Toast/searchOpen/query not reset on targetKey change; outbox fills even when `closedForGood`.
- tmux user-override (`remain-on-exit`, `destroy-unattached`) can invert `sessionAlive`.

## What's solid (praise)

- The credential strip (Cookie/Authorization/X-Caddy-*) on the proxy is correct and valuable.
- `csrfGuard`'s `Origin: null` rejection + the sandbox together do block the preview from POSTing to `/api` as the user (good defense-in-depth).
- The ingress-token check, JWT-key pin, and os.Root containment from the prior batches all held up under re-review.
- The tmux-detach *intent* (N16) is right; only the matching is buggy.

## Resolution (applied 2026-08-27)

**Blocking — all fixed:**
- B1 — `getClips` now returns a stable reference (swaps only when TTL expiry
  shrinks the list); added an e2e Clips-tab open check (34/34).
- B2 — added `identity.User.Authorized`; the owner branch requires an
  authorized user (`previewAllowed`), so a slug collision can't grant a guest.
  Unit-tested incl. the collision case.
- B3 — `has-session`/`kill-session` now use `=`-prefixed exact targets.
- B4 — styrman host set to ModeAuthenticated (removed the `caddy_admins`
  label); admin is server-side via `STYRMAN_ALLOWED_EMAILS` only. A shared
  guest signs in with Google and reaches only shared previews.

**Important — all fixed:**
- I1 — SPA catch-all now 404s any non-`Authorized` identity.
- I2/I3 — `sessionAlive` logs probe errors and returns `probed`; close-code
  decision extracted to `closeDecision` (unit-tested); the probe is skipped
  when the browser is already gone.
- I4 — kept sandbox (operator decision); documented; wildcard preview
  subdomain is the 1.1 path (see TODO).
- I5 — ingress strips client-supplied upstream claim headers before authorize.
- I6 — ShareBox disables editing until the list loads and uses the PUT
  response as state (no wipe-from-stale / lost-update).
- I8 — port validated before the cross-owner scan.

**Nits fixed:** version build-arg wired; share-list caps (50 / 254B) + audit
log; credential-strip prefix sweep + `Proxy-Authorization`; `u.Username`
mutation removed; `apiError` → `fmt.Errorf`; health uses cheap `Ping` not
`Adopt`; a11y `opacity` not `visibility`; IME guard; keep-email-on-failure;
toast reset on switch; outbox guarded by `closedForGood`; honest share copy.

**Deferred to 1.1 (TODO.md):** public signed TTL preview links on
`*.preview.styrman.xyz`; EnsureSelfAttached attach cache; `projectID→owner`
index; per-port (vs per-project) share scoping; path-traversal normalization
in the proxy; bridge sessionAlive integration test behind an Exec interface.
