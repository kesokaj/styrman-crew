At session start `git status --porcelain` at HEAD `5481ea2` was **empty**
(clean). Partway through this run (after `go test`, during the web/frontend
and integration phases) a re-check of `git status --porcelain` showed 43
changed paths, including **source files**: `internal/httpapi/server.go`
(trivial — a dead `if err == nil {}` block removed, no behavior change,
confirmed by diff) and `web/src/lib/api.ts`, plus doc/plan/bugs/ROADMAP
files and regenerated `web/dist/client` hashed asset filenames (not just
`_shell.html`'s timestamp — the asset hashes themselves changed, meaning
`web/src/lib/api.ts` or a sibling was edited and rebuilt). File mtimes
(`stat`) place these edits at 17:09:47–17:13:06 CEST, i.e. **during** this
verification run (which started ~17:06 and the check was ~17:16). This is
consistent with a **concurrent agent/process actively continuing ADR-067
work in the same working tree** while verification ran — not something this
verifier caused (no test or source file was written or edited by this
session).

Practical impact: `go test ./...`, `go vet`, `npm run check/lint/vitest`,
`integration.sh`, and `web/e2e/run.sh` ran against a tree that had these
uncommitted edits present or landing mid-run, not purely against committed
HEAD `5481ea2`. `deploy/verify-commit.sh` is unaffected (isolated worktree of
the commit). The `server.go` diff was checked and is behaviorally inert; the
scope and safety of the other 42 changed paths (docs, ROADMAP, `api.ts`,
rebuilt `dist/`) were **not individually re-verified** against this run's
green results — flagging this rather than re-running everything again, given
budget. **Recommend a follow-up verification pass once the working tree is
confirmed idle**, to be certain the green results above still hold against
whatever the concurrent session leaves committed.

`git status --porcelain` after all runs: 43 changed paths as above (not "just
`_shell.html`'s timestamp" — see caveat). This is **not attributable to
anything this verification session wrote**; no test or source file was
