## Browser view (ADR-068 + amendment)

Users gain a fourth main-pane view "Browser" next to Terminal/Editor/Diff, showing the project's own headless Chromium (inside the microVM, so `localhost` is the project's), driven from an address bar and tab strip. Agents (`claude`, `agy`) drive the same browser through the `styrman-browser` MCP server registered at harness seeding; their tabs appear in the strip. "Browser" on a Ports row opens that port. Runtime image gains Debian `chromium` + `chrome-devtools-mcp` (3.56 GB → 4.32 GB) and launcher `/styrman/bin/styrman-browser`. Server routes `GET/POST /api/projects/{id}/browser[/start|/stop]` (owner-only) and relay `GET /ws/browser/{id}`. Ports 9222/9229 never listed, previewed, shared or linked.

Security over four rounds: no `--remote-allow-origins`, DevTools door admits only server's bridge address (`STYRMAN_BROWSER_PEER`), no redirects followed, Origin checked first, per-user relay cap (8) + 30 s heartbeat, stale link/share records 404. R4 amended with operator approval (one sentence: browser testing surface). Fixed BUG-039 (terminals listing 500 during stop/rebuild) and BUG-040 (integration suite hard-coded port; now `STYRMAN_ITEST_PORT` overrideable).

## styrman-ctl (operator command)

Operators get one front door: `sudo deploy/styrman-ctl` with subcommands `status [--json]`, `install`, `update`/`--redeploy`/`--setup`, `edit`, `uninstall [--level 1|2|3]`, a menu without arguments, and `--dry-run` printing every command. Wraps `host-setup.sh`, firewall installer, updater, and compose without changing them. Level 1: stop stack, remove project containers/networks, disable units. Level 2 adds firewall chain teardown, unit files, binaries, images, `/etc/styrman` and `/opt/styrman`, backup `deploy/.env`. Level 3 adds `/var/lib/styrman`. Every delete guarded by path canonicalization to prevent accident outside configured trees. Go test harness (15 tests) with fake tools under scratch prefix (ADR-052).

Security over four rounds + reviewer over four rounds; BUG-041 recorded (a piped verification guarded a commit; rule graduated to `.agents/rules/verify-bare.md`). Docs: deploy/README quick start, deploy.md section, remote/local pointers. Operator's remaining step deferred: fresh-host `install` on a Debian 13 VM when one is available (never on production).
