# v1.42.0 — per-project resources   (2026-10-05)

Gate: `.agents/docs/reviews/2026-10-05-preflight-v1.42.0.md` (SHIP, range
v1.41.1..b1eabeb). This release commit carries only the gate records.

- **Per-project resources (ADR-083).** Project VMs are sized to the whole host
  by default instead of Kata's 1 vCPU / 2 GiB. Each project has a "Resources…"
  dialog, and `GET`/`PUT /api/projects/{project}/resources`. A stopped project
  at another size is rebuilt on its next start. The Docker disk grows offline
  at boot. `STYRMAN_VCPUS`/`STYRMAN_MEMORY_MB` are removed. Entries:
  `changes/2026-10-05-1314-…-phase-1.md`, `-1326-…-phase-2.md`,
  `-1329-…-phase-3.md`, `-1355-…-phase-4.md`.
- **BUG-089:** `host-setup.sh` writes the Cloud Hypervisor shim wrapper and
  turns on memory reclaim.
- **BUG-090:** a delete no longer fails while Docker reports the exiting VM as
  a zombie.
- Review fixes after f507278 (8a92b6a, b1eabeb):
  - the setup-VM reaper waits out an exiting VM (1 minute per VM);
  - Tier 2 covers the disk-grow retry branch and checks that the suite's own
    remove took effect;
  - the e2e Resources check restores unlimited in its `finally`;
  - a `DestroySetup` zombie test.
- js-yaml 4.3.2 (`changes/2026-10-03-1038-…`).
