# The three lows v1.41.0 shipped with, fixed   (2026-10-03)

The operator: "Do it fix them". These are items 1–3 of
`reviews/2026-10-02-preflight-v1.41.0.md`, whose `## Outcome` section has the
details. Planned for v1.41.1.

- **The status path's character rule is the same in every locale.**
  `deploy/update/styrman-update` `write_status` spells the plain set out
  instead of using bracket ranges. Under the UTF-8 locale systemd gives the
  unit on dave, `[A-Za-z]` matched `é`. Test
  `TestStyrmanUpdateStatusPlainSetIgnoresTheLocale` failed first. A probe
  under C and under en_US.UTF-8: the production path accepted; `café`, a
  newline and a space refused.
- **Parked requests share one wait.** `GuestGoingAway`
  (`internal/orchestrator/ports.go`) now joins or starts one shared
  `awaitLifecycle` per project and container (`Orchestrator.lifecycleWaits`).
  The shared wait runs on its own 20 s context. Test
  `TestListeningPortsParkedRequestsShareOneWait`: 10 parked requests asked
  Docker 50 times in 5 ticks before the fix; at most 8 now. The eight
  lifecycle tests pass three times under `-race`. BUG-088 has the step.
- **The test helper checks owners.** `trustedTempDir`'s check
  (`ancestorProblem`) also refuses an ancestor owned by neither root nor the
  test's user. Test `TestStyrmanUpdateStatusTempHelperChecksOwners` feeds it
  stand-in directories (a real one needs root); its two other-user cases
  failed first.

Counts: `TestStyrmanUpdateStatus*` 15, `ports_lifecycle_test.go` 8.

## Learnings for the local host
None beyond the first item: systemd hands units `LANG=en_US.UTF-8` on dave, so
a root script's bracket ranges are not ASCII there.
