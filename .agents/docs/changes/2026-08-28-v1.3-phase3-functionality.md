## Summary

- **Terminal names at creation** (item 4): an empty title now gets a
  generated friendly name (`internal/conversation/names.go` — adjective-noun,
  nautical to fit the brand, collision-avoiding per project) instead of
  "Terminal N". Rename lives in the header (unchanged) AND the sidebar row
  (new pencil → PromptDialog).
- **History, understandable and searchable** (item 6): the listing joins
  transcript files with their terminal's friendly title (transcripts
  deliberately outlive deleted records — those keep the raw conv-N id), and
  a new `GET .../history/search?q=` greps ALL transcripts server-side
  (case-insensitive, ANSI-stripped, os.Root-confined; bounded: 4 MiB tail
  per file, ≤20 hits/file, ≤200 total). The History tab gets a search box;
  hits show the terminal name + matching line, click-through to the
  transcript.
- **Markdown preview + JSON format** (item 19): `.md` files open in a
  RENDERED preview (micromark, raw HTML escaped — no sanitizer needed) with
  a Preview/Edit toggle; `.json` files get a Format button (2-space
  pretty-print into the editor, Save to keep). New `prose-md` typography in
  index.css, token-driven for both themes. New dep: micromark (justified:
  smallest safe CommonMark renderer; lazy-loaded with the viewer).
- **Settings overhaul** (items 14 + 12): the Admin "User access" card is
  GONE (operator Q4 — enforcement and the admin API endpoints stay;
  `allowedUsers` also removed from the `GET /api/settings` payload, closing
  the reviewer-noted leak to non-admin sessions). Runtime settings are now
  genuinely dynamic for admins: idle timeout (applies to the reaper
  immediately) and docker disk (new VMs) editable via `PATCH
/api/settings/runtime`, persisted in `StateDir/settings.json` over env
  defaults. Config fields moved behind mutex accessors
  (`cfg.DockerDiskGB()`, `cfg.IdleTimeoutD()`) — the reaper goroutine reads
  them concurrently.
- **Dashboard** (item 15): the home route with projects is now a card grid —
  every project with state, running ones showing LIVE transcript tails per
  terminal (last lines, 8s refresh, bell indicator), click to jump into the
  terminal. Empty state unchanged.
- **Files crumb shows the friendly name** (item 9's second half): plumbed
  `projectName` from the terminal route → SidePanel → FileExplorer; the
  UUID stays in the crumb tooltip and the page header.
- **Share copy states the lifetimes** (item 17 / D12): private = never
  expires until the email list empties; public = dies exactly at its TTL.

## Review fixes (reviewer subagent, same session)

One blocker found and fixed:

1. **Idle timeout `0s` at runtime = reap everything.** The reaper checked
   "0 = never" once at goroutine start; a live change to 0 turned the
   comparison bound into `time.Since(last) > 0` — stopping every running
   project AND force-removing in-progress setup VMs, up to 6h after the
   click. Restructured: fixed 2-minute tick, timeout re-read ONCE per tick
   (skip when ≤0), the same value threaded into `stopIfIdle` and
   `ReapSetupVMs`. Bonus fixes from the same restructure: enabling the
   timeout at runtime now works when it booted disabled, and a shortened
   timeout applies on the next tick instead of the old timeout/4 cadence.

Should-fixes addressed: `SetOperator` persists FIRST (atomic
temp+fsync+rename like every other store) so a failed write never leaves
live state diverged; persistence failures are 500 + logged (was 400);
`loadOverrides` warns on garbage and re-applies bounds (hand-edited files
don't bypass validation); admin changes get an audit log line; search takes
`r.Context()`, caps files scanned (50 newest), and early-outs with one
whole-file Contains (was ~144ms/4MiB per non-matching file); dashboard
polls calmed (terminals 30s, tails 15s) and `usePolled` now pauses ALL
polling in hidden tabs (refreshing on return); RuntimeEditor validates
5-500 client-side (a typed 0 was silently "keep"); history search drops
out-of-order responses; markdown preview links get `target=_blank rel=
noopener`; dead `addUser`/`removeUser` client functions removed; spec row
fixed. New tests: config round-trip/keep/bounds/persist-failure/garbage-
file, updateRuntime handler (400s, 200+persist, payload), history-search
route (title join, scope, overlong query), friendlyName collision +
exhaustion fallback.
