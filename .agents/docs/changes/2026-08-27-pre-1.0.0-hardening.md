  `useSyncExternalStore`; e2e opens the Clips tab (regression guard).

  gain an owner's projects. Unit-tested.

  (`conv-1` no longer matches `conv-10`).
- Deployability: styrman host → ModeAuthenticated; a shared guest signs in and
  reaches only shared previews; admin stays server-side (STYRMAN_ALLOWED_EMAILS).
