# v1.42.2: one-search-per-user reverted; token line guarded   (2026-10-05)

Corrects `changes/2026-10-05-1541-v1.42.2-review-fixes.md` (review
`reviews/2026-10-05-review-ef22f5c-c350683.md`).

- **Per-user search cap reverted.** The history panel does not abort its
  previous search, so a quick second Enter got 429 "a search of yours is still
  running" and no results. The search code and test are back to ef22f5c: a
  server-wide limit of 4, which is what bounds the memory. One tenant holding
  all four slots is accepted as a retryable 429 (low). Aborting the client's
  previous search, with server-side cancel, is a follow-up. `api.md` describes
  only the server-wide 429.
- **The token line is guarded** in `remote.md` and `specs/styrman/deploy.md`.
  It installs only when the host has no token yet, says so when the file is
  missing or empty, and `shred -u`s the plaintext copy after installing.
