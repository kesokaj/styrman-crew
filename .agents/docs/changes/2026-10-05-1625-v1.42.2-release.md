# v1.42.2 — memory-bounded history endpoints, token-safe docs, e2e race fixed   (2026-10-05)

Gate: `.agents/docs/reviews/2026-10-05-preflight-v1.42.2.md` (SHIP, range
v1.42.1..12c573e). This release commit carries only records.

- **History search and transcript reads are bounded server-wide** (4 and 8
  in flight, else 429), with a 30 s write deadline. `GOMEMLIMIT=3GiB` sits
  under the server's 4g cap. A tenant can no longer crash-loop the server
  through these paths (v1.42.1's cap had made that cheap).
- **The git child's OOM reset is tested through `git()`**, and a failed reset
  is logged.
- **The token never goes through sudo:** `sudo --preserve-env` was verified
  to log the value on dave. The guides install a FINE-GRAINED read-only token
  from a file, only when the host has none, never an empty one, and shred the
  plaintext.
- **BUG-092 fixed:** the e2e round-trip check waits for the terminal's focus
  before typing; e2e passed twice in a row on the release commit.
- **Tests:** the reaper out-of-time test.
- **ADRs:** ADR-084 marked superseded; ADR-085 amendment 1.
- Entries: `changes/2026-10-05-1534-…`, `-1541-…`, `-1543-…`, `-1548-…`.

**Carried to v1.42.3** (gate rows 1–4, 6):
- one limiter for every heavy endpoint, starting with the editor's file read
  and the 8 MiB bodies, plus server timeouts — a medium, also live in v1.42.1;
- a real-server test of the write deadline;
- per-user fairness with a client-side abort;
- the token-snippet lows;
- the e2e harness's safety lows.

No host step in this release.
