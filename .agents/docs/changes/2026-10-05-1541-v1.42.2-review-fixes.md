# v1.42.2: review fixes before the tag   (2026-10-05)

Corrects `changes/2026-10-05-1534-v1.42.2-work.md` (review
`reviews/2026-10-05-review-v1.42.1-ef22f5c.md`).

- **Token step, corrected (medium).** The earlier stdin form
  (`gh auth token | sudo install … /dev/stdin /etc/styrman/gh-token`) would
  have made the operator's full-scope `gh` token the auto-updater's root token,
  overwritten an existing host's token, and could leave an empty file that
  passes the permission checks.
  - The guides now install a FINE-GRAINED, read-only token from a 600 file
    (`test -s` first), or use `styrman-ctl install --gh-token-file`.
  - A re-run on an existing host needs no token step.
  - Covered: `remote.md`, `specs/styrman/deploy.md` and `host-setup.sh`'s hint.
- **History search, one per user** on top of the server-wide 4, so one tenant
  cannot hold every slot. `TestHistorySearchIsOnePerUser` was red first.
  `api.md` documents both 429s.
- `compose_oom_test.go` checks `GOMEMLIMIT` inside the `styrman` service only;
  moving it to `caddy` fails the test.
