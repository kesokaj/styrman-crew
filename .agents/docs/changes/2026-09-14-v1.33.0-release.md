# v1.33.0 — Containerized server asserts ip_forward=0 at boot, harness refresh (2026-09-14)

## What changes for a user

- **Container boot:** a containerized server now asserts `net.ipv4.ip_forward=0` inside its container at startup, making R12's no-routing guarantee explicit.
