# v1.42.3: a read deadline for slot holders   (2026-10-05)

Review `reviews/2026-10-05-review-v1.42.2-a265b48.md`, finding 1 (medium,
introduced by a265b48).

- The editor's slot is taken before the body is read, and the server sets only
  a header timeout. So one user trickling 8 bodies could hold every slot and
  lock all tenants out of the editor (429). `acquireSlot` now also sets a 30 s
  read deadline (`slotReadTimeout`).
- `TestASlowBodyReleasesItsSlotAtTheReadDeadline` runs on a real server. With
  the deadline removed, the slot was still held 8 s later.
- `deploy.md`'s token scope names both repositories (the image build needs
  `kesokaj/styrman-harness`). The `run.mjs` usage comment is updated. `api.md`
  states both deadlines.
