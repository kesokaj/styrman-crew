# v1.40.0 — the agents update themselves, a terminal recovers by itself, harness v2.3.2   (2026-10-02)

Release of the work in `changes/2026-10-02-1749-tool-updates-harness-v2-phase-1.md`,
`changes/2026-10-02-1812-terminal-freeze-phase-2.md` and
`changes/2026-10-02-1902-ingress-masked-load-and-gate-fixes.md`
(plan `plans/2026-10-02-tool-updates-freeze-harness-v2.md`). Gate report:
`reviews/2026-10-02-preflight-v1.40.0.md` — SHIP. MINOR: new user-visible
behaviour, nothing an existing deployment must react to.

The operator asked for three things: the runtime image on current versions and
a look at why `claude` and `agy` could not be updated inside a project; a fix
for crew freezing until the window was reloaded; harness v2.3.2 in the image.
The work found four more that had to go in with them.

## What ships
- **claude and agy update themselves in a project** (BUG-080, ADR-077,
  ADR-080). agy lives in `/opt/agy`, owned by the project user; the entrypoint
  creates the npm prefix Claude's updater installs into.
- **A terminal recovers without a reload** (BUG-085, ADR-079). A replaced
  terminal has "Use here" and comes back when its tab is shown again; a socket
  that died without a close is noticed by a ping the bridge now answers, and
  replaced in place.
- **Harness v2.3.2** (36 skills, 8 subagents), by ADR-074's signed release
  binary — the same release as the zip the operator linked. Its 1,788-file
  install runs after ready, in the background (ADR-078): boot-to-ready is
  about 3 s where it measured 16 s with the install in front.
- **Pins**: Node 22.23.3, Claude Code 2.1.287, OpenTofu 1.13.1, yq 4.54.1,
  chrome-devtools-mcp 1.10.1, both Debian base digests.
- **The ingress no longer takes a failed Caddy load for a success** (BUG-087).
  It cost six hours of crew on the day of this release.
- **`styrman-ctl install` writes a Cloudflare token the answers file carries**
  (BUG-081), and two unit tests red since v1.39.0 are green.
- **The integration suite measures the boot budget on disk** (BUG-082), 122
  checks; the browser suite has 99.

## Learnings for the local host
- This host does not take the tag by itself: its updater's GitHub token is
  rejected (BUG-084). The operator installs a fresh one; the steps are in the
  handoff. Until then it runs 1.38.0, with the ingress restarted by hand on
  2026-10-02 and still without the ingress fix — a reboot before the update
  can repeat the outage.
- Two things on this host failed silently for hours on the same day. Nothing
  watches the site from outside.
