# v1.3 Phase 2 — design system, rebrand, no native popups

Date: 2026-08-28. Second of four v1.3 phases (plan §4b: Q1/Q2/Q3 answers +
the responsive requirement). Phase 1 = 74e40c8.

## Summary

- **Material 3 token system** (`web/src/index.css`): tonal surface ladder on
  cool blue-tinted neutrals, Google-blue primary, light + dark palettes with
  new tokens (`on-accent`, `on-accent-soft`, `ok/warn/danger-soft`). The
  existing semantic token NAMES were kept and re-valued, so the whole app
  reskins without touching every className. Hex on purpose — terminal
  palettes mirror them.
- **Three-state theme** (light / dark / system, Cloud Console pattern):
  `useTheme` → `{pref, resolved, setPref}`; system = un-stamped `<html>` +
  `prefers-color-scheme` media block; live `matchMedia` listener; pre-paint
  script stamps only explicit choices. Controls: segmented icon radio in the
  sidebar footer + segmented control in Settings → Appearance.
- **Fonts**: Google Sans Flex Variable (UI) + Google Sans Code Variable
  (terminal/editor), self-hosted via Fontsource npm packages, bundled into
  the binary (~328K woff2 total, browsers fetch latin only). No CDN (R9).
- **Paired terminal ANSI palettes** (`lib/terminal.ts`): full 16-color M3-
  tinted light + dark themes, backgrounds mirroring `--term-bg`; swapped
  live via `term.options.theme` without recreating the terminal (scrollback
  survives). Terminal font is Google Sans Code.
- **crew rebrand**: geometric SVG mark (prompt chevron + baseline on a
  Google-blue rounded square) as `CrewMark` component AND `/favicon.svg`
  (finally linked — there was no favicon link at all); document title
  "crew"; sidebar wordmark; empty state. TanStack template leftovers
  (icons.svg, hero.png, vite.svg) deleted.
- **UI primitives** (`components/ui.tsx`): Button (filled/tonal/text/danger),
  IconButton (28px hit target), TextInput, Dialog, ConfirmDialog,
  PromptDialog, ToastHost + `lib/toast.ts` store. **All 11 native
  alert/confirm/prompt call sites replaced** (tryUI → toast; terminal
  delete/close-all, file discard/delete/rename/new-file/new-folder, project
  rename, checkpoint restore, setup done, user revoke → dialogs).
- **SVG icon set** (`components/icons.tsx`, Lucide-idiom inline, no dep) —
  replaces every unicode/emoji glyph incl. the 🔔 bell.
- **Files panel**: real icon buttons with hit targets (operator item 7),
  taller rows, file/folder icons.
- **Responsive** (desktop-first): below `md` the sidebar becomes an overlay
  drawer behind a top app bar (hamburger + mark + bell); below `xl` the side
  panel overlays the terminal and starts collapsed; dialogs and the viewer
  clamp to the viewport.
- **Also folded in** (already-decided items to avoid restyling twice):
  "run claude or agy here" header hint removed (item 3) — header now shows
  the project UUID dimmed (item 9's header half); LINKS bar removed
  (item 5; extraction machinery kept in lib/terminal.ts, unused); Clips tab
  renamed Clipboard with retention stated inline (item 10).

## Review fixes (reviewer subagent, same session)

Two blockers found and fixed:

1. **Sidebar drawer transform broke every dialog rendered inside it** — the
   always-on `translate-x-0` made the aside the containing block for
   `position:fixed` descendants, shrinking modals + scrims into the 256px
   rail (reviewer reproduced in headless Chromium). Fixed twice over: all
   dialogs (incl. the hand-rolled New/Delete-project ones) now render
   through `createPortal(document.body)`, and the drawer's transform
   utilities are `max-md:`-scoped so no transform exists on desktop at all.
2. **useTheme was per-component state** — four instances disagreed;
   switching the theme from the sidebar never reskinned the live terminal
   palette or an open editor, and a stale control could no-op entirely.
   Promoted to a module-level store on `useSyncExternalStore` (same pattern
   as clips/toasts); server snapshots return the prerender view, which also
   removes the new hydration-mismatch source in the theme radios.

Should-fixes addressed: **storage key bumped to `styrman-theme-v2`** (the old
hook wrote an unconditional explicit `dark`, which would have made the new
"system" default unreachable for every existing browser); `color-scheme` on
all three palette blocks (native selects/scrollbars follow the theme); new
`--on-danger` token (destructive buttons were navy-on-salmon in dark);
toast dedupe now refreshes the TTL instead of dropping repeats; dialog scrim
clicks stop propagating (nested discard-confirm was un-dismissable); Escape
closes only the topmost dialog (module stack); drawer gets `inert` when
closed on mobile + Escape-to-close; drawer z-index raised above the side
panel; PromptDialog's Enter can no longer bypass the disabled state. Nits:
stale link-bar doc comments cleaned, e2e now FAILS on any native browser
dialog (regression guard), AGENTS.md check counts corrected, `screens/`
gitignored.
