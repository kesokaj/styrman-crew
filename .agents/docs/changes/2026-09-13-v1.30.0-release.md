# v1.30.0 — Audit fixes and image supply-chain pins (2026-09-13)

**MINOR.** Base `v1.29.0` (`b6bc2bf`). Range `v1.29.0..HEAD` includes the
audit-fixes commits, security-round remediations, and the gate report.
Requested by the operator: "Now a full /audit of there are plenty of fixes
create a minor and use /preflight then commit and push."

## What changes for a user

- **Brokered credentials:** login shells receive the broker's env tokens
  (GitHub, npm, claude and friends), the gcloud ADC file, the ssh key and
  the git identity again. Broken in production since v1.27.1 (2026-09-10):
  the host pinned bridges to `/24` that day while the guest snippet still
  computed the broker address as broadcast−1 of a `/16` (BUG-054). The
  injected `STYRMAN_CRED_BROKER` is now authoritative (ADR-069); the guest
  no longer recomputes it, and a login shell whose broker did not answer
  says so in the MOTD.
- **Request timeouts:** start/stop and LAN toggle (150–210 s operations)
  are no longer clipped to 20 s by the API request layer; explicit
  caller timeouts are no longer overridden by a default bound
  (recurrence of BUG-022).
- **Git panel state:** Discard and a conflicting stash pop now sync the
  editor, leaving no stale buffer behind when git rewrites the tree.
- **Formatter config discovery:** temp file now lives beside the edited
  file, not in `~/.styrman/tmp`, so per-directory config (a monorepo's
  `.prettierrc`) is found by the formatter. A separate guard against
  workspace escape is enforced by the handler.
- **Runtime image determinism:** Go 1.27.1, Node 22.23.2, and
  claude-code 2.1.270 are pinned with their publishers' sha256 hashes.
  Antigravity floats by design (no upstream pinning mechanism). Rebuild
  procedure and bump checklist documented in ADR-069 and
  `runtime-image.md`.
- **Auth portal:** the post-login redirect trust is label-bounded (a
  leading dot) instead of a bare suffix that trusted `evil<base>`; the
  session cookie is `SameSite=Lax` and is cut out of requests that public
  previews and public apps tunnel into guest containers; the terminal and
  setup WebSockets refuse a cross-origin handshake before booting anything.
- **Updater:** the signature gate knows all four git signature markers and
  verifies in an empty GNUPGHOME; a hand-run `styrman-update --force` can
  no longer be routed to a keyring-only verifier by a decoy block.
