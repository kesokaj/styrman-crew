# v1.42.3 work: every memory-heavy endpoint bounded; harness and token lows   (2026-10-05)

Operator: "go v1.42.3". Answers rows 1–4 and 6 of
`reviews/2026-10-05-preflight-v1.42.2.md`.

- **The editor's file endpoints are bounded** (row 1, medium). `GET`/`PUT
  …/file`, `POST …/format` and `…/check` share `fileConcurrency` = 8
  server-wide slots, taken before any body is read, else 429. They get the
  same 30 s write deadline as search and transcript reads. A read holds up to
  about 12 MiB of JSON and the others take 8 MiB bodies, so this closes the
  last tenant crash-loop path under the 4g cap.
  - `TestEditorFileEndpointsAreLimitedServerWide` was red first.
  - `http.Server` already has `ReadHeaderTimeout`. A global `WriteTimeout`
    would cut terminal WebSockets and preview streams, so the bound stays per
    handler.
- **The write deadline is tested on a real server** (row 2).
  `TestASlowReaderReleasesItsSlotAtTheWriteDeadline` requests a ~24 MiB
  transcript, reads nothing, and asserts the read slot is taken and then freed
  after the deadline. With the deadline removed the slot was still held 8 s
  later. `historyWriteTimeout` is a var so the test can shorten it, and the
  `acquireSlot` comment no longer claims a fallback the server does not have.
- **The history panel aborts its previous search** (row 3), so a superseded
  search stops holding a server slot. `searchHistory` takes an `AbortSignal`
  combined with the 20 s bound, with a vitest case. The per-user server cap
  stays out (see ef04b30).
- **Token lows** (row 4):
  - `host-setup.sh` refuses an empty `/etc/styrman/gh-token`.
  - The doc snippet creates the plaintext file under umask 077, and reports
    each outcome (already installed / missing or empty / install failed / shred
    failed).
  - Step 8c names both repositories the token must read.
  - `deploy/.env` is created under umask 077 as a temp file, chowned and
    renamed, never world-readable.
- **e2e harness safety** (row 6):
  - `run.mjs` has no default `--base` (the old one was production's listener)
    and exits 2 without one.
  - It refuses a `STYRMAN_UPDATE_STATUS_FILE` outside `STYRMAN_E2E_STATE`.
  - Screenshots go to a private `mkdtemp` dir, printed by `run.sh`.
  - `run.sh`'s network cleanup removes only networks whose project UUID its own
    server logged.
  - A shellcheck warning in `run.sh` is fixed.
- Docs: `api.md` (the file endpoints' 429), `remote.md` / `deploy.md` (the
  token snippet), testing README (the e2e flags).
