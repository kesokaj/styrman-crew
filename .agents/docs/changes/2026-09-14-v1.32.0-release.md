# v1.32.0 — Terminal WebSocket boot attaches to project bridge (2026-09-14)

**MINOR** (operator's call). Base `v1.31.0` (release commit of 2026-09-14). Range `v1.31.0..340b045` plus the release commit: one substantive change, BUG-060 fix. The terminal-WebSocket boot path now attaches the server to the project's Docker bridge synchronously before the socket upgrade, eliminating the credential broker's unreachability for the first terminal of a stopped project after every server restart. No new commands, flags, endpoints, environment variables, or deploy steps. Web changes: none.

## What changes for a user

- **First terminal of a stopped project (after server restart):** the login shell no longer prints the credential broker MOTD. Brokered git, gh, ssh, gcloud, and claude credentials are available immediately.
