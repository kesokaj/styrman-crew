# BUG-063 fixed — Stop switches the restart policy off before the guest's own exit; Start and every attach switch it back on (2026-09-16)

## Summary

The Stop path now updates the container's restart policy to "no" before sending `kill -TERM 1` to the guest, preventing the daemon from restarting the VM during the shutdown sequence. Start and terminal attach restore the policy to "unless-stopped" before any operation on an existing container. The fix is minimal: two `ContainerUpdate` calls, conditional on success (NotFound returns nil, other errors log Warn and proceed). A stopped project's policy stays "no" until the next Start or terminal WebSocket boot.
