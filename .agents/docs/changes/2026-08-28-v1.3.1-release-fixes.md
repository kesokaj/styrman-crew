## Fixes (all deployed)

1. **Terminal delete 500 on a never-attached terminal**: `tmux
   kill-session` on a VM where NO tmux server ever started fails with
   "error connecting to <socket>" — now tolerated as nothing-to-kill in
   `conversation.KillSession` alongside the two known phrasings.
2. **Version stamp silently dead since the repo rename**:
   `deploy/Dockerfile.server`'s ldflags still targeted
   `github.com/kesokaj/styrman/...` (pre-rename module path) — the -X was
   ignored and prod reported "dev". Fixed; deploy with
   `STYRMAN_VERSION=x.y.z compose up -d --build`.
3. **Migration stub false-positives**: Docker recreates the workspace
   bind's mount-point stub (an empty dir) inside the home on every
   container start — the conflict warning and the `LegacyWorkspaceExists`
   guard now ignore EMPTY old dirs (unreadable still counts as content,
   fail-safe).
4. **dockerd boot-loop after an unclean VM stop**: /run is not a tmpfs in
   the runtime image, so a SIGKILL'd instance left stale
   docker/containerd sockets that made the next dockerd wait on a dead
   containerd until timeout ("dockerd did not become ready", observed
   live). The entrypoint now clears /var/run/{docker,containerd,docker.pid}
   before starting dockerd, and the readiness wait grew 30s → 60s.
