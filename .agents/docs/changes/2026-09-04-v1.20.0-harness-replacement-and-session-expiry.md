# v1.20.0 — harness replacement, session expiry, and guest symlink gates     (date: 2026-09-04)

## Summary

v1.20.0 is a composite release shipping the **agent harness replacement** (four phases, 2026-09-03 → 2026-09-04), **session-lifetime tuning** (ADR-063), and **three guest-writable-path security gates** discovered in review (ADR-062 amendment + R5 approved).

**Session expiry fix (BUG-001):** The SPA now re-authenticates once on session token expiry (900 s → 8 hours, ADR-063) instead of looping "Failed to fetch" toasts. Shipped as `.agents/docs/changes/2026-09-03-fail-to-fetch-session-expiry.md`. Sessions **survive this deploy**: the signing key is pinned; tokens issued before the release keep their old 900 s expiry until they lapse, then the new eight-hour tokens take over.

**Agent harness replacement (ADR-062):** Every project home seeded by the base image now receives a mirror of the operator's `styrman-harness` repo (commit `6893e2218414617da2bb88259b905ca3882b2659`, named in `image/harness/COMMIT`) installed by `sh-agent`. No hooks, scripts, or settings files are seeded — operator directive. Homes from the previous harness are backed up to `~/.styrman/harness-backup-<ts>/`, nothing deleted. The settings page shows the harness roster. Integration tests gained five checks (boot→ready latency, drift status, harness structure); `integration.sh` asserts 65 checks green on real Kata (62 passed, 0 failed, 3 skipped; boot→ready 1.7 s, R1 satisfied). See phases 1–4: `.agents/docs/changes/2026-09-03-harness-replacement-phase{1,2,3,4}.md`.

**Guest-writable symlink gates (BUG-002/003/004):** Bind-mounted home directories allow the guest (running as root) to plant symlinks that could redirect roots, the janitor, and Docker bind-source operations to cross-tenant paths. Fixed with `files.Trust` (`realBelow`, `projectHomeIsReal`), confined `MkdirAll` calls, the confined janitor, and a sub-root directory-entry-listing fix. Residual risk documented: the check-to-Docker bind window; un-nesting proposed in TODO.md. See `.agents/docs/changes/2026-09-04-v1.20.0-gate-fixes.md` and `.agents/rules/guest-writable-paths.md`.

**Session lifetime: 8 hours deliberately** (ADR-063): ingress `crypto default token lifetime` now set to 28800 s (working day). Trade-off: 8-hour cookie-theft window replaces 15-minute, but per-request `authGuard` re-checks remain, so role/admin changes take effect on next request regardless. See `.agents/docs/changes/2026-09-04-session-lifetime.md`.

**REQUIREMENTS.md R5 approved (ADR-062 amendment):** The operator approved the harness source name change on 2026-09-04 — R5 now reads "mirror of `styrman-harness`" and notes `image/harness/COMMIT` as the pin, operator-controlled via `sh-agent` at image build time. Previous harness ("vendored from `devshell_prompt/harness`") kept as history in the same sentence. No other R5 items change.
