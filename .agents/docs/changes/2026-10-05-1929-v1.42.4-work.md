# v1.42.4 work — memory budget, tenant shares, admin cap, BUG-074/091   (2026-10-05)

Plan: `plans/2026-10-05-v1-42-4-budget-fairness-cap.md` (cold read three
rounds; the residue settled by the operator, D20-D22). Operator: "go all";
per-tenant share "Half of each pool (Recommended)".

- **Memory budget (ADR-086, amendments 1-2):** `internal/membudget` (stdlib),
  1 GiB, 256 MiB per tenant, FIFO per tenant. `budgetGuard` (`internal/httpapi/budget.go`)
  sits between csrfGuard and the mux, prices each request by its matched
  route (`routeWeight`; unlisted: 2 MiB + body), waits up to 2 s, then 503
  "server busy, try again" with `Retry-After: 1`. It also applies the body cap
  (`bodyCap`, by route) and a 30 s body read deadline (uploads exempt).
  Tunnels are judged by route (`isTunnelRoute`) in csrfGuard and budgetGuard.
- **Slot shares:** each tenant holds at most half of each pool (file 4/8,
  transcript read 4/8, search 2/4); over the share: 429 "you already have N…".
- **408:** PUT `…/file`, `/format`, `/check` answer 408 when the body times out.
- **Listing bound:** `files.List` stops at 2 MiB of names plus paths too.
- **Admin cap (ADR-087):** `userMaxCpus`/`userMaxMemoryGiB` (0 = half the
  host) in Settings → Runtime; a non-admin's project starts at most at the cap
  (the record is kept); the Resources dialog shows "Unlimited (up to N)";
  PUT above the cap → 400; unchanged fields in a runtime PATCH are keep.
- **BUG-074 (ADR-088):** per-deployment cookie prefix `AUTHP<8 hex>`, policies
  read `<prefix>_ACCESS_TOKEN`, every deployment's portal cookies stripped
  from guest traffic. Verified by `caddy adapt` in the built image and a live
  caddy request.
- **BUG-091:** the identity fixture waits for the terminal's focus; must-fail
  (a) DIAG + failed=0, (b) failed=9, all in the identity's dependency chain,
  with the original 409s on git/commit and git/stash.
- **Token files:** `styrman-update` and `styrman-ctl` refuse an empty or
  whitespace-only token file; the deploy guides' snippet reads the token
  without echo into a new 600 file (`rm -f`, `set -C`).
- **History panel:** search state in `web/src/lib/historySearch.ts`; clear,
  an emptied box and leaving the panel cancel the search in flight.
- **e2e:** a green `run.sh` deletes its screenshots.
