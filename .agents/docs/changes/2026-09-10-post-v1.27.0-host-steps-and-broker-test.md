## Credential-broker reachability test (ADR-067 validation)

Owed since 2026-09-09 (`reviews/2026-09-09-security-adr-067.md`). Ran against the production compose deployment with two users (A: sandbox mode, B: LAN mode) to confirm broker isolation matches the documented (ADR-067) privilege model. Test results recorded in `testing/2026-09-10-broker-reachability-live.md`.

**Findings (all four probes matched expected outcome):**
- A's sandbox project reaches A's broker credentials (baseline 200), verified
- B's LAN project reaches B's broker credentials (baseline 200), verified
- B's broker endpoint times out when accessed from A's LAN project (connection refused, expected)
- B's host gateway is unreachable from A's LAN project (network drop, expected)
- Host uplink (outbound internet) refused from A's LAN project (expected under ADR-067)

**Incidental validation:** B's fresh project network at test time drew `172.16.0.0/24` from the newly pinned `172.16.0.0/12` address pool, confirming the host-setup pool configuration is live and allocating correctly.

**Teardown verified:** Test user, projects, containers, and networks all removed after test completion; A's sandbox project retained and re-verified to remain in sandbox mode (network state not corrupted by test run).
