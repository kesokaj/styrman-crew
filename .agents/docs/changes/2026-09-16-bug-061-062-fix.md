# BUG-061 and BUG-062 fixed — Tier 2 asserts the ADR-072 settings.json, the entrypoint logs the installer's attribution notes (2026-09-16)

## Summary
Commit 6a0b39e (2026-09-16, harness refresh to 4aa19be) added `~/.claude/settings.json` creation to the seeded home (ADR-072/R5 amendment), but the Tier 2 test asserting its absence was not updated, causing a FAIL run on that test. The entrypoint's `^settings:` log filter also dropped `note:` lines where the key could not be written, leaving the boot log empty in those advisory cases. Both fixed: the test now validates the file's presence and correctness; the filter now logs both `settings:` and `note: … attribution …` lines; five new Tier 2 checks cover the directory-planted edge case (BUG-062 persistence scenario).
