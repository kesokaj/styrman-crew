# Phase 2: ip_forward guard and attach tests     (date: 2026-09-14)

## Summary

Phase 2 of the v1.33.0 close-out plan (items 7, 3) added a containerized server ip_forward safety guard and three test suites for self-attach logic. Containerized server now reads `/proc/sys/net/ipv4/ip_forward` at boot and refuses to start when it is not `0` (the server joins every project bridge; forwarding on would violate R12). Knob `STYRMAN_ALLOW_IP_FORWARD=1` runs anyway with a Warn; missing sysctl file warns and continues; any other read error refuses unless the knob. Host-mode dev is exempt (host netns, never attaches). After security review, compose file gained the environment variable passthrough (finding 1, now fixed); IPv4-only rebutted (bridges created without EnableIPv6); fail-open error handling fixed.
