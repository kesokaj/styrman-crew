## What a user gets

**Provisioning feedback.** A new project's sidebar shows "provisioning…" while
git clone runs; the API's `state` field gains the value `provisioning`. Completes
the clone-on-create visibility arc (clone was background-only until the project
started; now the user sees real-time progress through project list).

**User revocation closes terminals.** When an admin removes a user, any open
terminals in that user's projects close within a minute with WS code 4003
("Access revoked"). REST routes already refused per-request; terminal close
completes the revocation timeline.

**Editor checkers, cancellable and selective.** The syntax gutter (squiggly lines)
now appears only for languages with a registered checker (Go, TypeScript, Markdown,
YAML, JSON, TOML). Checks are cancellable per debounce cycle. Files marked with
TOFU diagnostic (editor unsure of type) now receive "not formatted" errors instead
of nothing. Discard button on close now truly discards unsaved changes; prior
round left them in cache. Temp files (`/tmp/`) no longer appear in workspace tree.

**Settings → Credentials unifies parsers and tightens SSH.** Git committer and git
credentials now read through the same parser; a credential line that parses as
git committer identity cannot masquerade as a plain credential. SSH public key
line now requires a real OpenSSH type identifier (ed25519, rsa, etc.) and
sanitises the comment to alphanumeric + dash/underscore (no space, no tab escape).

**Network-mode toggle safety.** The API reply to a mode toggle is now written
AFTER the project's lock is released (not before), ordering the state change
before the client is told it happened. A failed stop leaves the toggle marker
only when the container is confirmed down via two independent samples (ADR-068).

## How it works

**Provisioning state:** A new project's creation is now three-state: `init` while
Docker setup runs, `provisioning` while git clone runs in guest, `running` when
the terminal connects. The sidebar queries state; frontend shows the
corresponding spinner or terminal.

**User revocation:** When a user is deleted from `StateDir/users/`, the server
scans open terminals and closes any belonging to that user. The scan runs every
10 seconds (configurable `revocationCheckInterval`).

**Editor checkers:** Checkers are now registered in a map; only registered types
trigger gutter updates. Debounce per file tracks the pending timer and cancels
on the next keystroke.

**Settings parsers:** Credentials and git identity both use `parseGitCredential`
and `parseGitIdentity` from the same package; neither accepts a line that
matches the other's grammar. SSH key regex now requires `^ssh-(ed25519|rsa|
dsa|ecdsa)` and caps comment at [a-zA-Z0-9._-]+ (no space, newline, tab).

**Network-mode lock ordering:** The Docker network rebuild and project start/stop
run under the project's `EnsureRunning` lock; the API response is written after
lock release, ensuring state on disk precedes state in browser.
