# v1.26.0 — network record durability and ssh key visibility   (2026-09-10)

A MINOR: two user-facing features added. Per-project network mode now writes
its state under the project's lock, making toggle-while-running safe and
allowing a toggle to repair a mode badge that disagrees with reality (BUG-032).
Settings → Credentials now shows the user's SSH public key (abbreviated in-line,
full on hover, with a copy button). Two security fixes from the gate also ship.
Net +650/−120 source lines.

Gated commit: `5df2959`; the release commit is the one carrying this entry and the gate artifacts. Gate report: `reviews/2026-09-10-preflight-v1.26.0.md`
(VERDICT: SHIP).

## What a user gets

**Network mode is durable.** The mode decision now lives under the project's
lock and is written only when nothing is in force (the API returns 409 if a
rebuild is running). Every project startup reads the mode under the same lock,
eliminating a toggle-vs-start race. Toggling the switch again will repair a
badge that disagrees with the bridge the project is actually on.

**SSH public key in Settings.** Credentials listing shows the SSH row with an
abbreviated public key (`ssh-ed25519 AAAAC3Nza…`), full text on hover, and a
copy-to-clipboard button. Users no longer need to SSH in to see which key is
live.

## How it works

Network mode record writes are now guarded by the project's per-start lock
(`EnsureRunning`), replacing a weaker check that only examined the recorded
state without testing the live bridge. On start, the mode is read under the
same lock and passed to orchestrator setup. The mode is no-op (no rebuild) if
the project's live bridge already matches the intent; the server determines
this by inspecting the bridge name in real time.

SSH public key display reads the secret through `files.ReadRawNoFollow`, which
opens the parent directory through the confined root and uses `openat` with
`O_NOFOLLOW` on the final path, closing an open `files.ReadRaw` guard that did
not prevent a symlink there. Frontend regex tightened: separators are now space
or tab only (no newline), 4096-char cap added, any line break rejected.
