## Findings

- **[medium / confidence: high]** `stale: .agents/docs/specs/styrman/api.md:266` (at HEAD) — the `STYRMAN_ALLOW_IP_FORWARD` row still says "A MISSING sysctl file warns and continues; any other read error refuses like forwarding-on." This range (`cmd/styrman/main.go`, `internal/config/ipforward.go`'s new `IPForwardMustRefuse`) deliberately removed that path: a missing sysctl file now refuses like every other read error. The function's own doc-comment states the change explicitly: "Until 2026-09-22 a missing file warned and continued... that made the one guard standing behind R12 report 'fine' in the single case where it had measured nothing." `api.md` was touched in this same range (the two rows immediately above this one, for the file-listing cap and the symlink guard) but this row was missed.

- **[low / confidence: high]** `stale: .agents/docs/testing/styrman/README.md:8` (at HEAD, Tier 1 description of `internal/config/ipforward_test.go`) — still reads "...`STYRMAN_ALLOW_IP_FORWARD=1` runs anyway with a Warn, a missing sysctl file warns and continues, any other read error refuses unless the knob". Same defect as above: `ipforward_test.go` gained `TestIPForwardMustRefuse` in this range, asserting the missing-file case now refuses, but the prose describing that test file was not updated to match.

- **[low / confidence: medium]** `narrowed: .agents/docs/specs/styrman/versioning.md:120-123 (text unchanged; behaviour changed in deploy/verify-commit.sh, this range)` — versioning.md's description of the release gate's web/dist freshness check still says it "compares file lists". `deploy/verify-commit.sh` changed the comparison from a bare `find … | sort` (names only) to `sha256sum` per file, specifically because a names-only comparison let a committed-but-stale `_shell.html`/favicon slip through as a "match" (the script's own added comment names this exact gap). The doc's "compares file lists" undersells what the gate now catches — content, not just names — which is the same class of gap this range's Phase 1 doc-truth pass otherwise closed elsewhere.
