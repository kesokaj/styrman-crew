# Review — v1.34.0-c26a723-docs (2026-09-16)

Range reviewed: v1.34.0..c26a723

Docs-lens review of BUG-063's fix (the container restart-policy race between
Stop's in-guest TERM and Docker's `unless-stopped` policy). Checked every
docs file the diff touched against the code it describes, and grepped the
old wording of every statement the diff changed or could have made stale
across the living docs (README.md, AGENTS.md, REQUIREMENTS.md,
`.agents/docs/specs/styrman/*.md`, the testing README, `.agents/docs/deploy/`),
excluding `changes/`, `DECISIONS.md`, `handoffs/`, `reviews/`, `retros/`,
and bug records as instructed.

## Verdict: APPROVE

Nothing broken. The one doc statement this range needed to change
(`restartPolicy`'s "Project VMs restart with the host" comment and the
guide's "Reboots" bullet) was changed at its only living-doc location, and
no stale duplicate of the old unqualified wording survives elsewhere. The
testing README's check count (106, `passed=103`) matches
`integration.sh`'s two new checks exactly, and the guide's "Stop is
sticky" bullet correctly describes the new Stop→`no`/Start-or-attach→
`unless-stopped` sequencing, with both callers (`stopLocked`,
`ensureRunningLocked`) confirmed in the code.
